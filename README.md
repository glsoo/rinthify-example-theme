# rinthify example theme

A small [Rinthify](https://github.com/glsoo/rinthify) theme to copy from. It sets the app's surface colors and has two
options: an accent color and rounder corners.

- `project.json`: the name, version and options
- `theme.css`: put on top of the app's styles. Each option is a css variable, and toggles set an attribute on `<html>`
- `theme.js` (optional): runs like a plugin while the theme is on, for things css can't do. This one adds a clock

To try it, paste `glsoo/rinthify-example-theme` in settings > themes and click install
